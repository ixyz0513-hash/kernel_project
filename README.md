# How to install powershell

## Ubuntu
`sudo snap install powershell --classic`

## Macos
`brew install powershell`

## Windows
`winget install --id Microsoft.PowerShell --source winget`


# How to build

## Ubuntu/Macos
`pwsh ./build.ps1`

## Windows
if inside powershell `./build.ps1`
